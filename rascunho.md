# PROBLEMA: 
Estou com a ideia de solicitar um programa que eu possa utilizar no celular. 

Programa este que funcione como um sistema de estoque como um GRUD, onde eu possa adicionar o produto, salvar, alterar e deletar. Hoje minha esposa controla as trufas que ela vende manualmente no grupo de whatsapp alterando a quantidade de trufas por sabores e compartilha com os clientes a quantidade ajustada. 

Este programa precisa ser escalável com possilidade de melhorias e novas funcionalidades para alavancar o negócio. 

# REQUISITOS: 
- Criar dentro dessa pasta aberta um ambiente virtual (.venv); 
- Ativar o ambiente para instalação das bibliotecas necessárias; - Salvar um arquivo requeriments.txt com as bibliotecas instaladas; 
- Como o programa vai rodar no celular android, o armazenamento dos dados podem ser registrado em um banco sqlite;
- Desenvolver o programa em python ou html (mais customizado); 
- Que a estrutura de arquivos e pastas seja possível para subir na minha conta github. 

DESIGNER: 
- Programa com uma interface atraente e moderna com sombreado leve;
- Telas e botões com bordas arredondadas.
